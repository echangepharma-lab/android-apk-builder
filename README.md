# ChatWorld — application Android

Première base technique de l'application de guide des chats.

## Version 0.1 incluse

- Accueil moderne en Jetpack Compose
- Recherche de races
- 6 races d'exemple
- Fiche détaillée : origine, prix indicatif, alimentation, soins, jouets, compatibilité
- Navigation Compose
- Premier carnet de vaccinations
- Architecture préparée pour une base de données et davantage de races

## Ouvrir le projet

1. Installer Android Studio récent avec JDK 17.
2. Ouvrir le dossier `ChatWorld`.
3. Laisser Gradle télécharger les dépendances.
4. Synchroniser puis lancer sur un émulateur ou téléphone Android.

## Étape suivante

- Remplacer les emojis par de vraies images de races.
- Ajouter une base Room persistante pour les chats, vaccinations et rappels.
- Ajouter 50–100 races.
- Ajouter favoris, profils de chats, rappels et notifications.
- Ajouter français/arabe/anglais.
- Préparer la signature et la génération APK/AAB.
